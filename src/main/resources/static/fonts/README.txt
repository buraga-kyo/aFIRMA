As fontes Archivo Black e Inter são distribuídas sob a SIL Open Font License.
As licenças e os avisos de autoria estão nos arquivos LICENSE-archivo-black.txt e LICENSE-inter.txt.

Fontes obtidas do repositório oficial Google Fonts:
https://github.com/google/fonts/tree/main/ofl/archivoblack
https://github.com/google/fonts/tree/main/ofl/inter

Os arquivos são servidos localmente para que as páginas de assinatura não dependam de requisições a um provedor de fontes externo.
